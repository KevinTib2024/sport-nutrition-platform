# Sport Nutrition Platform

Sport Nutrition is a web platform focused on promoting healthy habits related to exercise, nutrition and injury prevention.

The project was developed using ASP.NET Core with a layered architecture to ensure scalability, maintainability and clean organization of the backend services. Additionally, a Tidio chatbot was integrated to improve user interaction and support.

---

## Features

* Nutrition and exercise management
* Injury prevention guidance
* REST API architecture
* Layered backend architecture
* Database migrations with Entity Framework
* Integrated chatbot support
* Cloud deployment

## Architecture

The backend was developed using a layered architecture:

* Controllers
* DTOs
* Models
* Repository Pattern
* Services

This structure improves scalability, code organization and maintainability.

---

## Database

The database was implemented using Entity Framework migrations and SQL Server.
